# Project Website

This directory is the static project website for HiRA (Hierarchical Reach-Avoid Navigation for Quadruped Robots). It includes demonstration media and a description of Reach-Avoid learning with a frozen low-level locomotion controller. The original GitHub repository and Pages URLs remain valid after the local folder rename.

The GitHub Actions workflow at `.github/workflows/deploy-webui.yml` deploys this directory to GitHub Pages whenever `webui/` changes on `master`.

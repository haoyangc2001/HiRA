# Project Website

This directory is the static project website for HiRA (Hierarchical Reach-Avoid Navigation for Quadruped Robots). It includes demonstration media and a description of Reach-Avoid learning with a frozen low-level locomotion controller. Repository links use the renamed GitHub repository `haoyangc2001/HiRA`; its GitHub Pages address is `https://haoyangc2001.github.io/HiRA/`.

The GitHub Actions workflow at `.github/workflows/deploy-webui.yml` deploys this directory to GitHub Pages whenever `webui/` changes on `master`.

2.2 主要功能

（一）仿真环境构建：基于 Isaac Gym 搭建 Go2 仿真场景，支持机器人出生点与朝向的随机化，

以及障碍物与目标点的随机布置，使训练数据覆盖多样的初始条件。

（二）安全指标计算：在底层仿真环境中实时计算 avoid_metric（避障度）与

reach_metric（到达度），作为后续约束信号的基础。当距离障碍物或边界过近时，

avoid_metric 显著下降；当接近目标时，reach_metric 上升。

（三）高层观测构造：将安全指标与目标、障碍、边界的激光雷达分箱特征组合为 40 维观测向量，

为高层策略提供充分且低维的决策信息。

（四）约束信号转换：将底层指标转换为到达代价 g(s) 与安全约束 h(s)，使训练目标可由约束优化统一表达，

而非简单的标量奖励。

（五）策略训练：实现 Reach-Avoid PPO，以 g(s)/h(s) 经广义优势估计（

GAE）合成价值目标，更新高层策略参数。训练过程统计每轮成功率与执行成本，并支持断点续训。

（六）回放与评测：提供可视化回放脚本观察策略行为，提供轨迹导出脚本将评测结果保存为

JSON，便于离线统计成功率、碰撞率与执行成本。

（七）成果展示：提供基于 GitHub Pages 的静态网页，汇总算法原理、训练曲线与演示内容，

便于对外交流。

2.3 运行流程概览

典型工作流为：配置环境参数 → 启动训练（train_reach_avoid.py）

得到高层策略检查点 → 使用回放脚本（play_reach_avoid.py）观察行为

→ 使用评测脚本（test_reach_avoid.py）导出轨迹并统计指标 → 必要时绘制训练曲线（

plot_training_results.py）与场景布局（plot_env_layout.

py）。各步骤的输入输出均以文件传递。

第三章 架构设计与选型

3.1 总体架构

系统采用双层控制结构。高层策略输出速度命令，冻结的低层运动策略将速度命令转化为 12

个关节的目标动作，最终驱动 Go2 本体在仿真中运动。训练阶段，环境不返回标量奖励，

而是返回安全指标；高层环境将其转换成 g(s) 与 h(s)，经 Reach-Avoid

GAE 合成价值目标，用于更新高层策略。高层每决策一步，低层连续执行 5 步，形成分层时间抽象。

3.2 分层时间抽象

分层抽象是本软件的关键设计。低层策略以较高频率（每仿真步）运行，保证机器人稳定行走与抗扰；

高层策略以较低频率（每 5 个低层步）运行，只在“速度命令”这一语义清晰的接口上决策。

这种时间抽象降低了决策频次，使高层策略能在更长的视野上规划到达路径，同时低层始终维持安全的基本运动。

3.3 技术选型

仿真后端选用 Isaac Gym Preview 4，因其提供大规模并行物理仿真，可在单卡上同时采样大量环境，

显著提升强化学习的采样效率；底层封装沿用 legged_gym 框架；训练框架基于

rsl_rl 的 PPO 实现，并扩展出 Reach-Avoid 专用分支；深度学习框架为

PyTorch；全部功能以 Python 实现，便于科研人员阅读与复现。

采用分层而非端到端策略的原因：低层运动控制已由冻结策略保证稳定行走，高层只需在“速度命令”这一低维、

语义清晰的接口上决策，能够显著提升样本效率，并将底层不安全动作隔离在冻结策略之内，从结构上增强安全性。

提供的安全指标；分层环境（hierarchical_go2_env）装载冻结的低层策略，

无外部服务依赖。

第四章 详细功能阐述

4.1 环境模块

go2_env.py 在底层 Go2 仿真环境中扩展 _compute_safety_metrics()，

产出 avoid_metric 与 reach_metric，并随机化机器人出生点与朝向，

使策略对初始条件具有鲁棒性。该模块还负责物理步进、碰撞检测与回合终止判断。

high_level_navigation_env.py 将底层指标转换为到达代价

g(s) 与安全约束 h(s)：当机器人抵达目标附近时 g(s) 取较小的 g_target（

如 -300），距离越远代价越高（由 g_distance_scale 控制）；当处于安全区域时

h(s) 取 h_safe（如 -300），发生碰撞或越界时取 h_unsafe（如

300）。同时构造 40 维高层观测：8 维基础特征、16 维目标激光雷达分箱特征、

16 维障碍/边界激光雷达分箱特征。

hierarchical_go2_env.py 装载冻结的低层策略，实现分层时间抽象：

高层输出一个速度命令后，低层连续执行 5 步，再回到高层决策。该模块对上层屏蔽了关节级控制细节，

仅暴露速度命令接口。

go2_config.py 以配置类集中定义场地尺寸（12×12 米）、障碍球数量（

14）、目标半径（0.5 米）、训练轮数（1500）等关键参数，便于实验复现与消融。

4.2 算法模块

reach_avoid_ppo.py 是本软件核心。其中 _calculate_reach_gae()

以 g(s)/h(s) 计算广义优势估计，ReachAvoidBuffer 存储含约束信号的轨迹，

ReachAvoidPPO 类据此更新高层策略。该方法把“到达”与“避障”统一为带约束的策略优化问题，

区别于普通以奖励最大化为目标的 PPO。

actor_critic.py 定义多层感知机（MLP）策略网络与价值网络，隐含层均为

512×4，动作分布采用对角高斯，适用于连续动作空间。actor_critic_recurrent.

py 提供带循环单元（如 GRU/LSTM）的可选版本，用于需要处理部分可观信息的场景。

rollout_storage.py 管理训练轨迹的收集与批量采样；on_policy_runner.

py 组织训练循环，负责任务创建、日志写入、模型保存与评估调度，并支持从检查点恢复训练。

4.3 训练与评测脚本

train_reach_avoid.py 为训练主循环，按配置创建环境、初始化算法、

迭代更新策略，并在每轮统计成功率与执行成本，将检查点保存至 logs/ 目录，支持断点续训。

play_reach_avoid.py 用于可视化回放：加载训练好的高层策略，在仿真中运行并记录画面，

便于直观检查导航行为是否安全、是否绕障、是否抵达目标。

test_reach_avoid.py 用于批量评测：在多种随机初始条件下运行策略，

将轨迹与指标导出为 JSON 文件，便于离线统计成功率、碰撞率与平均执行成本。

plot_training_results.py 与 plot_env_layout.

py 分别读取日志与配置，绘制训练曲线（成功率、成本随轮数变化）与场景布局（场地、障碍、

目标分布），辅助结果分析。

4.4 工具与展示模块

utils 下提供 helpers（通用辅助）、terrain（地形相关）、task_registry（

任务注册）等模块；webui 为 GitHub Pages 静态站点，展示算法原理、

训练曲线与演示视频，便于成果对外交流与评审材料补充。

5.4 观测与动作空间

高层观测为 40 维向量，组成见图4-1：前 8 维为基础特征（含机器人位姿、速度、

与目标相对位置等）；中间 16 维为目标方向的激光雷达分箱特征；后 16 维为障碍/边界的激光雷达分箱特征。

动作空间为 3 维连续向量 [vx, vy, vyaw]，分别表示前进/后退线速度、

左/右平移速度、偏航角速度，范围由配置约束。

激光雷达分箱（lidar bin）指将机器人周围空间按角度划分为若干扇区，取各扇区内最近障碍（

或边界）的距离作为该扇区的特征值。这种表示既压缩了原始点云维度，又保留了绕障所需的方位信息，

适合作为高层策略输入。

5.5 安全指标说明

avoid_metric 反映机器人相对障碍物与边界的安全程度，值越高越安全；reach_metric

反映机器人相对目标的接近程度，值越高越接近目标。二者由底层环境的 _compute_safety_metrics()

计算，是构造 g(s)/h(s) 的直接依据，也是本软件“安全导航”能力的来源。

第六章 操作使用

6.1 训练操作流程

第一步，确认环境与依赖安装正确，CUDA 可用；第二步，在 go2_config.py

中确认场地、障碍、目标等参数符合预期；第三步，运行训练脚本 train_reach_avoid.

py 启动训练，控制台将按轮输出成功率与执行成本；第四步，观察日志，待成功率与成本收敛后停止训练，

检查点自动保存至 logs/。

训练过程中若成功率长期不上升，可检查随机初始化范围是否过难、学习率是否合适、以及安全指标计算是否符合预期；

若频繁碰撞，可降低目标距离权重或增大障碍数量以加强避障学习。相关超参均可在配置类与算法参数中调整。

6.2 可视化回放

运行 play_reach_avoid.py 加载已训练的高层策略，仿真将在图形界面中运行。

观察要点：机器人是否朝目标前进、是否在接近障碍物时减速或绕行、是否在回合内安全抵达目标。

回放可用于定性判断策略是否符合“安全导航”目标。

6.3 评测与轨迹导出

运行 test_reach_avoid.py 在大量随机初始条件下批量评测，脚本将每条轨迹的状态、

动作与指标写入 JSON 文件。离线可使用该文件统计成功率、碰撞率与平均执行步数（即执行成本）

，得到可量化的性能结论。

7.4 术语表

Reach-Avoid（到达—避障）：在抵达目标的同时满足安全约束的控制问题，本软件的核心建模方式。

分层强化学习：将决策分解为高层策略与低层策略的多层结构，高层在更粗时间尺度上决策。

冻结低层运动策略：预训练且在训练过程中参数固定的底层控制器，负责稳定行走，隔离不安全动作。

四足机器人分层安全导航强化学习训练平台 V1.0.0著作权人：曹豪洋第 13 页

高层策略：本软件的训练对象，输入 40 维观测，输出 3 维速度命令。

对角高斯策略：动作分布为各维独立高斯，仅学习均值与对数标准差，适用于连续动作空间。

Isaac Gym：NVIDIA 提供的并行物理仿真平台，用作本软件仿真后端。

PPO：近端策略优化，本软件训练所基于的 on-policy 强化学习算法。

GAE：广义优势估计，结合时序差分误差估计优势函数，稳定策略梯度。

激光雷达分箱（lidar bin）：将周围空间按角度分箱并取最近障碍距离，作为观测特征。

5.6 训练资源与耗时

训练对算力的主要消耗在大规模并行仿真采样与神经网络更新。本项目在单张服务器级 GPU

上完成 1500 轮训练，实际耗时约 21.5 小时；检查点与日志随训练写入磁盘，占用空间主要取决于保存频率与回放画面数量。

若显存或算力有限，可减少并行环境数量，相应延长训练时间。

5.7 配置示例说明

go2_config.py 以 Python 配置类集中管理参数，典型字段包括：场地边长

field_size、障碍球数量 n_obstacles、目标半径 target_radius、

到达代价 g_target 与距离缩放 g_distance_scale、安全代价

h_safe 与 h_unsafe、训练轮数 train_iters 等。修改这些字段即可调整任务难度与约束强度，

无需改动算法代码，体现了配置与逻辑分离的设计。

6.7 评测指标计算方法

成功率 = 在 N 个随机初始回合中安全抵达目标的比例；碰撞率 = 发生碰障或越界的回合比例；

执行成本 = 抵达目标所需的平均仿真步数（步数越少表示路径越短、效率越高）。三者结合可全面衡量“是否到达、

是否安全、是否高效”。test_reach_avoid.py 导出的 JSON 包含逐回合上述指标，

离线汇总即可得到报告。

6.8 结果复现建议

参数；在相同的 GPU 与 Isaac Gym 版本下训练；保存每轮日志以便绘制曲线。

若成功率偏离较大，优先检查安全指标计算与随机初始化范围是否一致。
